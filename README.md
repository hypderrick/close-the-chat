# 不怕关对话（close-the-chat）

让 AI Agent 靠**项目里的文件**而不是一段越来越长的对话来记住你的项目。对话随时可以关，新对话开起来就能接着干：额度花得少，效果不打折。

适用于 Claude Code、Codex，以及其他会读 `AGENTS.md` 的 Agent。

## 为什么需要它

和 Agent 长期合作一个项目时，人们往往不敢关对话，怕它忘事。但对话越长，每发一条消息，Agent 都要把整段上下文重新读一遍：

- **贵**：每一轮的成本和上下文大小大致成正比。上下文到 90 万 token 时，回一句「好的」的成本也是 10 万时的 9 倍左右。
- **不一定更好**：旧日志、早就放弃的尝试堆在上下文里，反而容易让它引用过时的信息。

不怕关对话的做法是：**一个对话只做一件事；值得留下的东西当场写进文件；事情做完就关掉对话。** 下一个对话读文件就能接上。

## 你只需要做一件事：说出需求

其余的由 Agent 按规则负责：

- **要不要新开对话**：你提的是另一件事时，它会提醒你，并帮你新开对话，或者给你一句话直接粘贴到新对话里。
- **记住规则和风格**：你纠正它、定下偏好时，它会提议写进文件。**写之前一定先问你。**
- **进度**：做不完的事记在 `进度.md`，问它「做到哪了」就行。
- **收尾**：你说可以了，或者它判断已经到了可验收的状态并经你确认后，它会做沉淀检查、更新进度，再问你要不要归档对话。

## 开始使用

到 [Releases](../../releases) 下载最新的 `close-the-chat-v*.zip` 并解压，里面有 `使用说明.md` 和 `项目启动包/` 文件夹。

**新项目**：复制一份 `项目启动包/`，改名为你的项目名，用 Agent 打开它，直接说你要做什么。

**已有的项目**：把整个 `项目启动包/` 文件夹复制到项目根目录，然后对 Agent 说：

```text
按 项目启动包/机制/改造说明.md 改造这个项目
```

它会先提醒你备份，再给你一张方案表，你确认后才动手。旧文件都会保留在 `_改造前/` 里。

**升级到新版本**：把新版的 `项目启动包/` 复制到项目根目录，然后说：

```text
按 项目启动包/机制/升级说明.md 升级这个项目
```

它只替换通用规则，你项目自己的流程、规则、风格和进度都不会动。

## 项目结构

```text
你的项目/
  AGENTS.md    规约：「本项目」的流程 + 通用的「工作机制」
  CLAUDE.md    只有一行 @AGENTS.md（让 Claude Code 读到同一份规约）
  沉淀/        从合作中提炼的规则、风格
  进度.md      跨对话的事项和状态（需要时才建）
  机制/        参考资料：改造说明、升级说明、看板规范、默认视觉风格
```

只维护 `AGENTS.md` 一份规约。Claude Code 从 v2.1.277 起支持 `AGENTS.md`，但项目里有 `CLAUDE.md` 时默认只读 `CLAUDE.md`，所以这里用 `@AGENTS.md` 引用它。
