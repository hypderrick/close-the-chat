# 黑金控制台设计规范（Black-Gold Console）

适用范围：各类本机控制台、看板、管理后台。
给实现者（Agent）：所有颜色、字号、间距都用下面的 CSS 变量，**不要另起颜色**。需要新颜色时，先在第 2 节补充，再使用。

---

## 1. 气质

- **黑底、金线、克制。** 金色是“信号”，不是“装饰”：只用来标出当前、重点、可操作的东西。整屏金色面积不超过 8%。
- **有层次的暗：** 背景、面板、卡片、内嵌区是四层不同深度的黑褐色，靠明度差和 1px 细线分层，不用大面积阴影。
- **数字用等宽字体**（计时、token 数、编号、时间戳），像仪表盘；正文用中文无衬线字体。
- **动效少而准：** 只有“正在运行”的元素会呼吸，其他元素保持静止。

## 2. 设计令牌（CSS 变量）

```css
:root {
  color-scheme: dark;

  /* 底色层级：从深到浅 */
  --bg:            #050403;  /* 页面背景 */
  --bg-bar:        #0c0a06;  /* 顶栏 */
  --inset:         #0a0907;  /* 代码块、内嵌区 */
  --panel-a:       #201a10;  /* 主面板渐变起点 */
  --panel-b:       #100e0a;  /* 主面板渐变终点 */
  --card-a:        #17140f;  /* 列表卡片渐变起点 */
  --card-b:        #110f0b;  /* 列表卡片渐变终点 */
  --surface:       #1D1A14;  /* 普通表面、输入框 */
  --chip:          #252119;  /* 徽章、小块底色 */

  /* 线 */
  --line:          #3A3730;  /* 默认分隔线和边框 */
  --line-warm:     #332d22;  /* 卡片边框 */
  --line-gold:     #56431e;  /* 重点面板边框 */
  --track:         #3a3221;  /* 进度条底轨 */

  /* 文字 */
  --text:          #F4F2EC;  /* 主文字 */
  --text-2:        #cec5ad;  /* 次要强调 */
  --muted:         #8A8780;  /* 说明、时间戳 */
  --label:         #ddc489;  /* 小节标题（暖金灰） */

  /* 金 */
  --gold:          #EDB91A;  /* 主强调：当前、数值、焦点 */
  --gold-hi:       #ffe19a;  /* 悬停高光 */
  --gold-soft:     #e7bd5d;  /* 编号、次级金 */
  --gold-deep:     #634801;  /* 深金：图标描边、按下态 */
  --on-gold:       #0A0806;  /* 金色底上的文字 */

  /* 状态色：低饱和，和黑金协调 */
  --ok-fg: #bad3a7;  --ok-bg: #1e281a;  --ok-line: #3c4e32;   /* 通过、完成 */
  --run-fg:#ffdc74;  --run-bg:#35270d;  --run-line:#75591e;   /* 运行中、等决定 */
  --bad-fg:#edb4a4;  --bad-bg:#321e18;  --bad-line:#5f3c2f;   /* 停止、退回、失败 */
  --info-fg:#ced0e6; --info-bg:#242433; --info-line:#414158;  /* 已汇报、待审、中性信息 */
  --online:#94b27b;  --offline:#f0a08b;                       /* 连接指示灯 */

  /* 字体 */
  --font: "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
  --mono: ui-monospace, "SF Mono", Menlo, Consolas, monospace;

  /* 字号令牌：对应第 3 节 */
  --size-h1: clamp(30px, 3.2vw, 44px); --size-h2: 22px;
  --size-card: 16px; --size-body: 14px; --size-small: 12px;
  --size-number: clamp(24px, 3vw, 38px); --size-stamp: 11px;

  /* 圆角与间距 */
  --r-panel: 10px;  --r-card: 8px;  --r-btn: 5px;  --r-pill: 99px;
  --gap-1: 4px; --gap-2: 8px; --gap-3: 12px; --gap-4: 16px; --gap-5: 24px; --gap-6: 40px;
}
body { margin:0; background:var(--bg); color:var(--text); font-family:var(--font); font-synthesis:none; }
```

**规则：**
- 不用纯白 `#fff`，也不用纯黑以外的冷灰（蓝灰、紫灰都不用）。所有灰色都带暖色调。
- 状态色只用在徽章、细线和小圆点上，不用来铺大面积底色。

## 3. 字体与字号

| 用途 | 字号 | 字重 | 其他 |
|---|---|---|---|
| 页面大标题 H1 | `clamp(30px, 3.2vw, 44px)` | 650 | 字间距 .065em，行高 1.18 |
| 小节标题 H2 | 22px | 650 | 字间距 .04em |
| 卡片标题 | 15–17px | 600 | 悬停时变为 `--gold-hi` |
| 正文 | 14px | 400 | 行高 1.7 |
| 说明、标签 | 12px | 400–600 | 小节标签带 .12em 字间距，颜色用 `--label` |
| 大数字、计时 | `clamp(24px, 3vw, 38px)` | 600 | `--mono`，字间距 -.06em，金色 |
| 编号、时间戳 | 11–12px | 600 | `--mono` |

大数字后面的单位（例如“张”“分钟”“token”）用 12px 正文字体和 `--muted` 颜色，并且**禁止换行或被截断**（`white-space:nowrap`；容器窄时，数字自己缩小）。

## 4. 组件

### 4.1 顶栏
高 66px，背景 `--bg-bar`，底边 `1px solid #2d281a`。
- 左侧是品牌：27px 方形图标，深金描边，内画两道金色斜线；名称字间距 .13em。
- 右侧是连接状态：6px 圆点（在线时用 `--online`，并带 9px 光晕）加 12px 文字。

### 4.2 小节标签
一个 5px、旋转 45° 的金色菱形，加文字。用 `--label` 色，12px，字间距 .12em。

### 4.3 面板（Panel）
- 边框 `1px solid var(--line)`，圆角 `--r-panel`，内边距 23px 25px。
- **重点面板**（当前任务等）：
  - 边框改用 `--line-gold`；
  - 背景：`radial-gradient(ellipse at 98% 0%, #39280c 0%, transparent 52%), linear-gradient(130deg, var(--panel-a), var(--panel-b) 78%)`；
  - 顶部加一条金线：`::before` 1px 高，`linear-gradient(90deg, var(--gold), #edb91a05 80%)`，左右各缩进 25px。
- 普通面板背景：`linear-gradient(145deg, #1c1912, #100f0c)`。

### 4.4 列表卡片（Card）
- 背景 `linear-gradient(100deg, var(--card-a), var(--card-b))`，边框 `1px solid var(--line-warm)`，圆角 `--r-card`，内边距 14px 18px。
- 悬停时边框亮一级，标题变为 `--gold-hi`。
- **运行中：** 边框改用 `#695321`，左侧加 2px 金色内描边：`box-shadow: inset 2px 0 #c69515`。

### 4.5 状态徽章（Badge）
- 胶囊形：内边距 4px 9px，字号 11px，前面带一个 5px 的小圆点。
- 配色按状态取第 2 节的状态色：运行中和等决定用 run，通过用 ok，停止用 bad，已汇报用 info。
- 只有“运行中”的圆点做呼吸动效（见第 5 节）。

### 4.6 进度条
- 高 4px，圆角 9px，底轨用 `--track`，填充色用 `--gold`。
- 达到上限的 80% 时，填充色改为 `--bad-fg`。
- 上方是标签行：左边写名称（12px，`--muted`），右边写“当前 / 上限”（`--mono`，11px）。

### 4.7 指标格（Metrics）
- 2 列网格，相邻格之间用 `1px solid #373125` 分隔。
- 每格是一个 12px 的标签，下面是大号等宽数字，数字后面跟单位。

### 4.8 流程步骤条（Stepper）
- 横向排列的节点和连线。节点是 22px 圆形，里面写序号或图标；下面依次是步骤名（12px）、执行者（Claude、Codex 或“你”）、时间（`--mono` 11px）。
- 节点状态：
  - **已完成**：实心 `--gold`，序号用 `--on-gold` 色；
  - **当前**：金色描边，带呼吸光晕；
  - **未到**：`--line` 描边，序号用 `--muted` 色。
- 连线：已完成的段用金色，未完成的段用 `--line`。
- 执行者标识：Claude 用金色、Codex 用 `--info-fg`、“你”用 `--run-fg`，三者用色要统一。
- 步骤条下方放一行大字摘要：“现在：…… · 上一步：…… · 下一步：……”。
- 窄屏（≤620px）时改为纵向排列。

### 4.9 “轮到谁”徽章
- 放在右上角，比普通徽章大一号：字号 14px，内边距 8px 14px。
- 轮到“你”时用 run 配色，并带呼吸效果，确保一眼能看到。

### 4.10 提示条（Notice，例如“需要你决定”）
- 背景 `#2a1e08`，边框 `1px solid #715518`，圆角 8px，内边距 12px 17px。
- 放在列表顶部，左侧放一个金色的菱形标识。

### 4.11 按钮
- **主按钮**：底色 `--gold`，文字 `--on-gold`，圆角 `--r-btn`，内边距 8px 14px，字重 600。悬停时底色变为 `--gold-hi`。
- **次按钮**：透明底，边框 `1px solid #5d4b2e`，文字 `--gold`。悬停时底色变为 `#262015`。
- **筛选按钮或标签页**：未选中时文字 `#a9a396`，选中时底色 `#2a2210`，边框 `--line-gold`，文字 `--gold`。

### 4.12 抽屉（详情）
- 从右侧滑出，宽度 `min(560px, 100%)`，背景 `#0e0c08`，左边框为 `--line-gold`。
- 遮罩用 `#000a`。
- 右上角的关闭按钮：34px 方形，深金描边，按钮上的字用金色。

### 4.13 Markdown 正文
- 标题用金色系：h2 用 `--gold-soft`，h3 用 `--label`。
- 行内代码：颜色 `#f0ce7c`，底色 `#272116`。
- 代码块：底色 `--inset`，加 1px 的 `--line` 边框。
- 表格：表头底色 `#1a160f`，单元格之间用 `--line` 分隔。
- 链接：用 `--gold`，悬停时加下划线。

### 4.14 输入框与表单
- 底色 `--surface`，边框 `1px solid var(--line)`，圆角 `--r-btn`，文字 `--text`，占位文字 `--muted`。
- 获得焦点时：边框改为 `--gold`，外加 `0 0 0 3px #edb91a22` 的光圈。

### 4.15 空状态
用虚线边框（`1px dashed var(--line)`），文字为 `--muted`，13px，居中，配一句人话说明。

## 5. 动效

```css
@keyframes pulse { 50% { opacity:.4; box-shadow:0 0 13px #edb91aa0; } }
.is-running .dot, .step.current .node { animation: pulse 2.1s ease-in-out infinite; }
@media (prefers-reduced-motion: reduce) { * { animation:none !important; transition:none !important; } }
```

- 悬停和切换的过渡统一使用 `transition: .18s ease`。
- 抽屉的滑入效果是 `transform .22s ease`。
- 数据刷新时不能闪烁，也不能整页重绘，只更新数值。

## 6. 布局

- 页面内容宽度：`min(1184px, calc(100% - 96px))` 并水平居中。宽度 ≤620px 时，左右各留 16px 边距。
- 页面从上到下的顺序：
  1. 顶栏；
  2. 页面标题区：左边是小号金色路由文字（`--mono`）加 H1，右边是更新时间；
  3. 概览区：主面板 1.65fr，统计面板 1fr；
  4. 列表区：标题、计数和筛选按钮在同一行，下面是卡片列表。
- 断点：
  - ≤850px：概览区改为单列；
  - ≤620px：卡片改为纵向排列，步骤条改为纵向。
- 页面任何地方都不能出现横向滚动条。

## 7. 文案

- 全部使用中文，口语化，例如写“等你决定”，不要写“Pending User Action”。
- 时间格式：`2026-11-21 19:40`。时长：“12 分钟”“00:12:31”。大数字加千分位逗号。
- 状态用词要统一：待派、运行中、已汇报、通过、停止、退回、等你决定。

## 8. 无障碍与质量门槛

- 正文和背景的对比度不低于 4.5:1。`--muted` 只用于辅助说明，不用来承载关键信息。
- 获得焦点时要显示金色外框：`outline: 2px solid var(--gold); outline-offset: 4px`。
- 所有可以点击的区域都要用 `button` 或 `a`，键盘能操作。
- 交付前自查：
  - 宽度 1440、800、375 三种情况下各截图检查；
  - 没有被截断的单位和文字；
  - 没有出现规范之外的颜色；
  - 运行中的元素有呼吸效果，其他元素是静止的。
